## 1. 一句话定位

一个**可运行、可演示、可度量**的 GenAI 职业助手工程：左侧是 LangGraph 多场景 Agent（9 个求职场景），
右侧是企业知识库 RAG 引擎（上传 → 混合检索 → 重排 → 带引用问答）；对外提供 Streamlit 演示界面与
FastAPI 服务，内置评测体系（Recall@5 / MRR / HitRate / 幻觉率 + 双路径 A/B）。

## 6. 关键工程决策（每条一句"为什么"）

1. **工具调用用 LangGraph 条件边**，不用 `AgentExecutor` / 手写 `while` —— 项目约定"多轮推进权归 SessionManager"，工具调用是**单轮内**闭环。
2. **显式检索与 Function Calling 两条路径都保留**且共享同一套工具实现 —— 可 A/B、可回退，避免"同一件事两条路径行为不同"。
3. **手写 MCP 客户端**（零新增依赖）—— stdio 协议面小，换来可离线验证、不受三方 SDK 版本牵动。
4. **外部工具接入同一套闭环** —— 失败分级 / 轨迹指标 / 熔断 / 取消**自动覆盖**，无需为每类工具重写治理。
5. **权限是装配期授权**（不挂载），**不是沙箱** —— 如实划清：装配期授权 / 运行期拦截 / 沙箱三档。
6. **失败分级 + 带标记降级**（`【工具降级:kind】`）—— 让"没查成"与"没有"在模型眼里是两件事。
7. **降级文案分渠道**（web=未联网核实 / kb=未取得资料依据 / mcp=该工具结果不可用）—— 说错渠道会给出错误的免责声明。
8. **取消是协作式的、三个检查点**（排队期间 / 流式分片之间 / 工具轮次之间）—— 断连后继续跑就是在烧用户额度。
9. **数据时效由工具算好再回灌** —— 模型没有时钟、也不做日期减法。
10. **隐私优先**：日志只记 query 摘要；span 不记原文与片段；MCP 快照不含 command / env。

## 8. 真实缺陷清单（全部有修复与回归记录）

**跨端"看着正常、数据其实丢了"（4）**
1. 流式接口绕过会话层 → 完整回复既没进 `history` 也没进 `record`（多轮上下文与归档全空）。
2. 流式回复未落库 → 归档接口拿不到 AI 产出。
3. 雪花 ID 精度丢失 → 回传 `position_id` 已错，`user_context` 静默注入失败（改由 Jackson 序列化为字符串）。
4. 长结构化调用被中间层 120s 读超时掐断 → SSE 每 15s 心跳保活。

**契约类（2）**
5. `MockInterviewAgent.respond` 丢 `model / max_tokens` → 走会话链路必 `TypeError`。
6. 子类覆写吞会话参数 → 补"所有 Agent 必须接受三参数"的契约测试。

**指标失真（2）**
7. 检索 15/15 全挂，报告仍写"工具失败率 0%"（轨迹只统计实验组）。
8. 对照组路径 `ok` 写死为 True → 降级不可见。

**数据时效（2）**
9. `RetrievedChunk` 丢 `meta` → 入库时间在**检索出口**被截断（工具只能靠源文件路径反推）。
10. 入库链路根本没记文件时间。

**语义错误（1）**
11. 知识库检索失败被说成"未检索到相关内容" → 模型据此凭记忆作答。

**环境类（3）**
12. Windows `.cmd` / `.bat` 不能被 `subprocess` 直接 spawn（须经 `cmd.exe /c`）。
13. Defender 实时防护锁 `.vite` → Vite 依赖预构建 504。
14. 本机 D 盘安全删除策略拦截构建产物重命名。

## 10. 已知边界（诚实清单）

- **MCP**：只实现 tools 能力与 stdio 传输；单连接串行；连接池在进程内（多副本各自持有）。
- **权限**：装配期授权，不是沙箱；当前风险面小是因为工具面只有检索类（无执行/写文件类工具）。
- **任务生命周期**：状态在进程内（多副本需 Redis）；非流式 `/chat` 只有"开始前"检查点。
- **数据时效**：阈值（365 / 180 天）是策略参数；多版本冲突只做"摆出跨度"，未做版本裁决。
- **并发写仲裁**：结构上没有（串行单写者），只能讲清"引入并行后怎么做"。
- **覆盖率缺口**：OTel 真实 tracer 路径需装 SDK 才能覆盖（`telemetry.py` 67%）。
- **`docs/DEV_NOTES.md`**：已创建（2026-09-19，preflight-check skill 阶段 0）：项目速览 / 常用命令 / 端口（8501 Web、8000 API）/ 目录与"偏离默认"约定 + 踩坑记录；门禁里的 DEV_NOTES WARN 项随之消除。
- **评测集规模**：20 条 / 知识库 10 片段 —— Recall@5 已饱和，指标分辨力需扩大数据规模才有意义。
