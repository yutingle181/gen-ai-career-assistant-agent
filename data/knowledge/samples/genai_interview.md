# 生成式 AI 应用工程师面试常见考题

## 一、RAG 方向

1. 讲一下 RAG 的完整链路，每一环节你踩过什么坑？
2. chunk_size 怎么选？过大过小分别有什么影响？
3. 为什么要做混合检索？BM25 和向量检索各自解决什么问题？
4. RRF 融合的公式是什么？相比加权求和有什么优势？
5. 重排模型和 Embedding 模型的区别是什么？为什么不能只用 Embedding？
6. 如何评测一个 RAG 系统？Recall@K 和 MRR 分别怎么算？
7. 如何降低幻觉？如果资料里没有答案，应该怎么处理？
8. 遇到召回率低的 case，你的排查顺序是什么？

## 二、Agent 方向

9. Function Calling 的执行流程是什么？模型输出工具调用后系统做了什么？
10. 什么场景下用 ReAct，什么场景下用计划-执行（Plan-and-Execute）？
11. 多 Agent 协作时如何避免死循环？如何设置最大步数与超时？
12. LangGraph 相比裸 LangChain Agent 的优势是什么？
13. 如何做工具调用的错误恢复与重试？
14. 结构化输出有哪些实现方式？Pydantic 校验失败时怎么兜底？

## 三、工程与成本

15. 如何统计和控制大模型的 token 成本？
16. 流式输出（SSE）的实现原理是什么？
17. 模型超时、限流、异常输出分别怎么处理？
18. 如何设计 Prompt 模板与上下文管理策略？
19. 长对话导致 token 爆炸怎么办？
20. 内容安全如何做？输入输出两侧的过滤策略有何不同？

## 四、项目深挖（几乎必问）

- 你的项目里召回率是多少？怎么测的？
- 做了哪些优化？每一步提升多少？
- 如果让你重做，你会改哪里？
- 你们的知识库有多少文档？多少片段？延迟多少毫秒？
